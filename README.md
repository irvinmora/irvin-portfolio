# Portafolio Profesional - Ingeniero en Sistemas

Portafolio web moderno y responsive para mostrar proyectos y habilidades como desarrollador web full-stack en formación.

## 🚀 Características

- **Diseño Moderno**: Interface limpia y profesional con gradientes y animaciones
- **Totalmente Responsive**: Se adapta a todos los dispositivos
- **Secciones Completas**:
  - Presentación/Hero
  - Sobre mí
  - Habilidades técnicas con barras de progreso
  - Grid de proyectos
  - Formulario de contacto
  - Footer con enlaces sociales
- **Interactividad**:
  - Navegación suave
  - Animaciones al hacer scroll
  - Formulario de contacto funcional
  - Menú móvil

## 🛠️ Tecnologías Utilizadas

- HTML5 semántico
- CSS3 con Flexbox y Grid
- JavaScript Vanilla (ES6+)
- Font Awesome para iconos
- Google Fonts (Poppins y Roboto Mono)
